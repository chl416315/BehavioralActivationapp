# 비를 기다리지 않는 법 기록장

「비를 기다리지 않는 법」 행동활성화 14일 워크북을 따라 하루씩 적는 기록 앱입니다.
링크를 연 사람마다 **자기 기기에 따로** 기록이 저장됩니다. 서버나 로그인은 없습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다 (예: `rain-log`, Public).
2. **Add file → Upload files**에서 이 폴더 안의 파일을 전부 올립니다.
   `index.html`, `manifest.webmanifest`, `sw.js`, `icons` 폴더가 저장소 맨 위에 있어야 합니다.
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 두고 Save.
4. 1~2분 뒤 `https://<아이디>.github.io/rain-log/` 주소가 생깁니다. 이 링크를 나눠 주면 됩니다.

## 휴대폰에서 앱처럼 쓰기

- **아이폰(Safari):** 링크 열기 → 공유 버튼 → 홈 화면에 추가
- **안드로이드(Chrome):** 링크 열기 → 메뉴(⋮) → 홈 화면에 추가 (또는 앱 설치)

한 번 열고 나면 인터넷이 없어도 열립니다.

## 기록은 어디에 저장되나요

- 지금 쓰는 기기의 브라우저 안에만 저장됩니다. 다른 사람은 볼 수 없습니다.
- 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라질 수 있으니,
  **막힐 때 → 기록 백업**에서 가끔 백업 파일을 내보내 두세요. 새 기기에서 같은 곳에서 불러오면 됩니다.

## 고쳐서 다시 올릴 때

`index.html`을 고쳐 올린 뒤 `sw.js` 맨 위의 `bwnw-v1`을 `bwnw-v2`처럼 바꿔 주면
이미 설치한 사람들도 새 버전을 받습니다.
